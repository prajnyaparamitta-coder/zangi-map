このサイトについて

ザンギの地図 は、北海道の店のザンギを集め、地図から店を選ぶとその店のザンギの動画と情報が見られるサイトです。今は 55 店を載せています。

出典と帰属表示

地図
地図の画像とデータは © OpenStreetMap contributors のものです。データは Open Database License（ODbL）で提供されています。地図の表示には Leaflet を使っています。
店の位置
OpenStreetMap にある店や建物の位置、または OpenStreetMap の地図を見て人が置いた位置を使っています。一部の店は、「街区レベル位置参照情報（2025年版）国土交通省」「大字・町丁目レベル位置参照情報（2025年版）国土交通省」（北海道 01_2025.csv）をもとに、住所との突き合わせを行って作成しました（作成：ザンギの地図）。店名からの位置の検索には Nominatim を使いました。
動画
動画は YouTube の埋め込みプレーヤーで流しています。動画の著作権は投稿者にあります。このサイトは YouTube API サービスを使って動画を探し、動画の公開状態を週に1回確かめています。YouTube 利用規約が適用されます。
店の情報
店名と住所は、店の公式サイト、動画の説明欄、グルメサイトで確かめた事実を、このサイトが書き起こしたものです。紹介文や写真は写していません。

プライバシーポリシー

このサイト自体は、閲覧した人の個人情報を集めていません。Cookie やアクセス解析、広告は使っていません。ただし、ページを表示すると、次のサービスにブラウザーから直接アクセスします。

  • YouTube（Google）：動画の埋め込みに YouTube のプレーヤー（プライバシー強化モード）を使っています。動画を再生すると、YouTube が Cookie などで情報を集めることがあります。このサイトは YouTube API サービスを使っています。Google による情報の扱いは Google プライバシーポリシーをご覧ください。
  • OpenStreetMap：地図の画像を OpenStreetMap Foundation のサーバーから読み込みます。その際に IP アドレスなどが送られます。OpenStreetMap Foundation のプライバシーポリシーをご覧ください。
  • GitHub Pages：このサイトは GitHub Pages で公開しています。GitHub がアクセスの記録を残すことがあります。GitHub のプライバシーに関する声明をご覧ください。

このポリシーは 2026年11月2日 に定めました。変えるときは、このページで知らせます。
