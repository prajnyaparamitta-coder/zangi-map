ザンギについて

このサイトに載せている店

載せているのは、北海道内の店が「ザンギ」の名前で出している鶏のザンギです。タコなど鶏以外のザンギ、道外の店、道外で似た名前で呼ばれる料理は載せていません。コンビニやスーパーの商品も載せていません。

動画がある店だけを載せています

このサイトは、地図から店を選んでザンギの動画を見るためのものです。そのため、YouTube でザンギが紹介されている店だけを載せています。載っていないことは、その店の良し悪しとは関係ありません。あとから動画が公開されれば、その時点で載せます。

地図のピンについて

ピンの位置は、OpenStreetMap の地図や国の住所の位置データをもとに決めています。決め方は店ごとのページに書いています。店の入口とは少しずれることがあります。
